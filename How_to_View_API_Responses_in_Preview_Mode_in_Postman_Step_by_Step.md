# How to View API Responses in Preview Mode in Postman (Step-by-Step)

In this tutorial, you'll learn how to use **Preview** mode to view API
responses in a table format.

------------------------------------------------------------------------

## Step 1: Open the Request

Open the **Get Devices** request.

------------------------------------------------------------------------

## Step 2: Send the Request

Click **Send**.

Wait for the API response to be returned.

------------------------------------------------------------------------

## Step 3: Open Preview Mode

In the **Response** section, click **Preview**.

------------------------------------------------------------------------

## Step 4: View the Response

Expand the **data** array.

View the API response as a table.

Scroll horizontally to see additional columns.

------------------------------------------------------------------------

## Step 5: Switch Back to JSON

Click **JSON** to return to the raw JSON response.

------------------------------------------------------------------------

## Note

Preview displays the JSON response in a table, making it easier to read
and inspect API data. It does not modify the response or export it to
Excel or CSV.
